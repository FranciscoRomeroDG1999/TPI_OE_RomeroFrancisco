# Historia de usuario 3

Como empleado de administración, quiero ser notificado al momento que esté listo el reporte de alumnos vencidos para poder leerlo.

Prioridad: ALTA
Asignada a: Programa AFI
Tecnología: Python
Rama: feature/notificar_administracion

## Criterios de aceptación

- [ ] Crear función 'notificar_administracion'.
- [ ] La función debe tomar como parámetro el reporte generado por la función 'crear_reporte'.
- [ ] Debe ser capaz de enviar el reporte a la casilla de correo comunicada por administración.
- [ ] También debe capturar y mostrar errores de forma clara por pantalla.
